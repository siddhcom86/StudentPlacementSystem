# 🎓 Student Placement Management System

### 💻 A Java-Based Student Record Management Application

A simple, menu-driven console application built using **Core Java** to manage student records and perform basic placement-related operations. This project demonstrates fundamental Java programming concepts through practical implementation.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| ➕ Add Student | Register new students with their details |
| 📋 View Students | Display all available student records |
| 🔍 Search Student | Find students using their unique ID |
| ✏️ Update Student | Update student CGPA |
| 🗑️ Delete Student | Remove student records |
| ✅ CGPA Validation | Validate CGPA within the 0–10 range |
| 🛡️ Duplicate ID Check | Prevent duplicate student IDs |
| 🎯 Placement Eligibility | Check eligibility based on CGPA |
| 📊 CGPA Sorting | Sort students from highest to lowest CGPA |

---

## 🛠️ Tech Stack

- **Language:** Java
- **Concepts:** Object-Oriented Programming (OOP)
- **Data Management:** Java Collections Framework (`ArrayList`)
- **User Input:** `Scanner`
- **Development Environment:** Visual Studio Code

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK)
- Visual Studio Code
- Java Extension Pack for VS Code

### Run Locally

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Open the project folder**

Open the downloaded folder in Visual Studio Code.

**3. Run the application**

Open `Student.java` and run its `main()` method.

**4. Explore the menu**

Use the terminal menu to add, search, update, delete, and view student records.
